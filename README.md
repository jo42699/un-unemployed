
# AI Interview Questions and Answers

I was studying the theory behind Artificial Intelligence and LLMs, focusing on how they operate in modern industries, to strengthen my knowledge and prepare for potential technical interviews. I found a few resources online some required payment, while others were useful but not as in-depth as I wanted.

Eventually, I found a repository that contained exactly what I was looking for. The only problem was that it was extremely long, and I had to either manually search through it for answers or copy and paste sections into an LLM. I decided to make a simple webpage that organized all the questions and answers in one place.

Then I thought, “Someone else might find this useful too,” so I decided to make it open source and share it with others.

Nothing too complicated just HTML pages and CSS. I didn’t even bother putting images into a separate folder. Initially, I only had a very simple page that directed me to the different colour coded topics but my CSS skills are about as good as yours, so I got some help from ChatGPT to improve the design.

For the content, I used a combination of resources including Copilot, Claude, ChatGPT, Wikipedia and Google to help answer and organize the questions.

Credit goes to Amit Shekhar for the original repository. His GitHub is linked on the platform, but you can also find it here:
https://github.com/amitshekhariitbhu

Anyway, hopefully this helps someone else on their AI journey. Maybe we can all become **un-unemployed** together.
